# 여행 콘텐츠 자동 게시·색인 범용 지시문

## 목표
`daytrevel.com`과 `stay.daytrevel.com`에 검색 의도 중심의 오리지널 여행 콘텐츠를 게시하고, 하루 게시분이 완료된 뒤 Google Search Console과 네이버 서치어드바이저에 색인 신청한다.

## 게시 일정과 분량
- 월요일부터 토요일까지 매일 실행한다.
- 하루 총 10편을 게시한다.
- 기본 배분은 다음과 같다.
  - `daytrevel.com`: 국내 여행 콘텐츠 5편
  - `stay.daytrevel.com`: 해외여행·숙소 콘텐츠 5편
- 별도 지시가 있으면 배분을 조정하되, 총량과 대상 사이트를 기록한다.

## 키워드 사용 순서
1. 지정된 Google Sheets의 대기 중인 세부키워드를 먼저 사용한다.
2. 넓은 단일 키워드보다 지역·대상·시기·문제·행동 의도가 2개 이상 드러나는 롱테일 키워드를 우선한다.
3. 이미 게시된 글의 제목·슬러그·핵심 주제와 중복되지 않도록 확인한다.
4. 현재 키워드 묶음 100개를 모두 작성한 뒤, 다마고치의 여행 키워드 분석에서 11~12월 시즌에 맞는 새 세부키워드 100개를 수집한다.
5. 다마고치의 키워드와 수치만 참고하고, 문장이나 콘텐츠는 복사하지 않는다.
6. 새 키워드 묶음은 Google Sheets에 새 탭으로 저장한 뒤 작성에 사용한다.

## 콘텐츠 작성 기준
- 원본성이 있는 실용적인 여행 정보로 작성한다.
- 공식 출처를 확인할 수 있는 운영시간, 요금, 예약, 교통 정보만 사용한다.
- 확인되지 않은 가격·혜택·운영 여부를 단정하지 않는다.
- 제목과 본문은 사용한 세부키워드의 검색 의도에 직접 답해야 한다.
- 과장된 수익 문구, 억지스러운 광고 문구, 키워드 반복을 피한다.
- 사이트의 기존 글 구조와 저장소 규격을 따른다.
- 게시 전 빌드·링크·슬러그·렌더링 오류를 점검한다.

## 링크 기준
- 같은 사이트의 실제 관련 글 2~4개를 자연스럽게 내부 링크로 연결한다.
- `daytrevel.com`과 `stay.daytrevel.com` 사이의 교차 링크는 정말 관련 있을 때만 사용한다.
- 교차 사이트 링크는 글당 최대 1개로 제한한다.
- 링크를 늘리기 위해 무관한 글을 연결하지 않는다.
- 애드센스 수익과 사용자 경험을 해칠 수 있으므로 전체 링크 수를 과도하게 늘리지 않는다.

## Trip.com 제휴 링크 기준
- 실제 글의 내용과 관련된 Trip.com 상품 또는 검색 페이지가 있을 때만 링크를 넣는다.
- Trip.com 공식 제휴 도구에서 생성한 딥링크만 사용한다.
- 관련 딥링크가 없으면 일반 Trip.com 링크를 임의로 만들지 않는다.
- 제휴 링크를 포함한 글에는 링크 바로 위 또는 글 하단에 다음 고지문을 반드시 넣는다.

> 이 글에는 트립닷컴 제휴 링크가 포함되어 있습니다. 링크를 통해 예약이 이루어지면 운영자에게 수수료가 지급될 수 있습니다.

- 제휴 링크가 없는 글에는 제휴 고지문을 넣지 않는다.
- Trip.com의 PPC, 유료 검색, 키워드 입찰, 금지 키워드 광고를 하지 않는다.
- 제휴 링크 여부와 고지문 삽입 여부를 Google Sheets에 기록한다.

## 게시 후 색인 루틴
1. 하루 10편의 게시를 모두 완료한다.
2. 실제 공개 URL과 HTTP 접근 가능 여부를 확인한다.
3. 공개 URL만 Google Search Console과 네이버 서치어드바이저에 색인 신청한다.
4. 게시에 실패했거나 URL이 없는 글은 색인 신청하지 않는다.
5. 색인 신청 결과, 날짜, 도구별 성공·실패 상태와 실패 사유를 Google Sheets에 기록한다.
6. 동일 URL을 불필요하게 반복 제출하지 않는다.
7. 색인 신청은 검색 노출을 보장하는 행위가 아님을 기록한다.
8. 색인 도구의 로그인, 소유확인, CAPTCHA, 제출 한도, 권한 문제로 진행할 수 없으면 우회하지 말고 실패 사유만 기록한다.

## Google Sheets 기록 항목
각 글마다 다음을 기록한다.
- 사용한 세부키워드
- 사이트
- 예정 게시일과 실제 게시일
- 제목
- 공개 URL
- 상태
- 같은 사이트 내부링크 수
- 교차 사이트 링크 여부
- Trip.com 링크 여부
- Trip.com 제휴 고지 여부
- Google 색인 신청 결과
- 네이버 색인 신청 결과
- 오류 또는 보류 사유

## 실패 처리
- 저장소 접근, 로그인, 권한, DNS, 빌드, 배포, 사실 확인에 문제가 있으면 무리하게 게시하지 않는다.
- 실패한 글은 키워드 상태를 완료로 바꾸지 않는다.
- 실패 원인과 다음 조치만 시트에 기록한다.
- 기존 글 삭제·대량 수정·코드 삭제는 별도 지시 없이는 하지 않는다.
- 외부에 공개되는 게시·색인·설정 변경 전에는 최종 확인 절차를 거친다.
